# ai-native-week1

Week 1 assignment for AI Augmented Software Engineering course.

## Overview
This repository provides:
- **`agent_scaffold.py`**: An interactive CLI tool to prompt for agent metadata and scaffold a ready-to-use CrewAI agent setup.
- **`market_research_analyst_agent.py`**: A generated CrewAI agent configured as a Senior Market Research Specialist.

## Generated Agent Configuration
- **Agent Name:** Market Research Analyst
- **Role:** Senior Market Research Specialist
- **Goal:** Identify emerging AI trends in fintech
- **Backstory:** You are a seasoned analyst known for uncovering market opportunities

## Usage
Run the scaffold generator CLI:
```bash
python agent_scaffold.py
```

Run the generated agent:
```bash
python market_research_analyst_agent.py
```
